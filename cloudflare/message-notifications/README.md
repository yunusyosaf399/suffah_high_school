# Android message pushes (Spark + Cloudflare)
Deploy Firestore rules/indexes first. In Google Cloud enable Firebase Cloud Messaging API (HTTP v1). Create a dedicated service account with Cloud Datastore User and Firebase Cloud Messaging API Admin roles. Keep its JSON private; never commit or embed it in the Flutter application. Store the entire JSON as a Cloudflare secret FCM_SERVICE_ACCOUNT with wrangler secret put FCM_SERVICE_ACCOUNT (or dashboard secret). Deploy with npm install and npx wrangler deploy. Cron runs every minute, processes one queued message per run and up to 20 registered devices per message. Retries may duplicate notification if partial send succeeds; Android notification tag reduces visible duplication. Messages older than 24 hours are skipped for push; dashboard history remains. Existing messages before this feature do not generate alerts. Native Windows push is intentionally absent. No Firebase Functions required for immediate-message notifications. Scheduled chat delivery itself remains a separate undeployed feature.
